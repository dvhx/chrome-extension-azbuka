How to use it

On any page select text you want to translate to your language. Right-click and choose "Azbuka (selection)" and it will be transliterated to your alphabet. If you don't select anything, the popup menu will have option "Azbuka (entire page)" which will transliterate entire page. You can also click on yellow "Az" icon in top-right corner of Chrome to show popup where you can type text and see translation.

Report issues

If you find any errors with translations, please report them on project's github page: https://github.com/dvhx/chrome-extension-azbuka/issues.
Especially if you are native speaker.
